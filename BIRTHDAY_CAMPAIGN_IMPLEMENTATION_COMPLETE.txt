================================================================================
⏰ HOW IT WORKS
================================================================================

SCHEDULE: Daily at 10:00 IST (04:30 UTC)

WORKFLOW:
  1. Cloudflare Cron trigger fires at 04:30 UTC
  2. Worker.js scheduled() handler invokes
  3. Calls /api/jobs/birthday-campaign-daily with SYNC_SECRET
  4. API endpoint:
     - Validates Bearer token
     - Acquires sync lock (prevents duplicates)
     - Syncs user DOB to KV cache
     - Gets today's date in IST
     - Fetches user UIDs from Firestore
     - Loads profiles from KV (fast cache)
     - Matches birthdays (MM-DD format, IST timezone)
  5. For each birthday:
     - Create/reuse 15% discount coupon (30 days valid)
     - Send email via Brevo + HTML fallback
     - Send WhatsApp via Aisensy
     - Log results in Firestore
  6. Backup cron at 04:35 UTC (in case first failed)

BACKUP: If first run fails, second cron runs 5 minutes later
LOCK: Prevents duplicate runs (30-minute lock TTL)
