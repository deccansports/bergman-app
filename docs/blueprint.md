# **App Name**: AffirmationCraft

## Core Features:

- Personalized Affirmation Tool: Generate unique, uplifting affirmations based on a short prompt or selected theme provided by the user using a generative AI tool.
- Affirmation Display: Present generated affirmations in a clean, focused, and inspiring format, optimized for readability.
- Favorite Affirmations: Allow users to save their favorite affirmations for easy access later. Data will be stored locally on the user's device for MVP.
- Daily Reminder Function: Enable users to set up simple daily notifications to receive a new or favorited affirmation.
- Share Affirmations: Provide options to easily share an affirmation as text or an image to social media or messaging apps.

## Style Guidelines:

- Color Palette based on concepts of calm, inspiration, and positivity, using a light color scheme. Primary color (uplifting blue): #668CCC. Background color (desaturated light blue): #EDF1F7. Accent color (vibrant cyan): #26C7DD.
- Body and headline font: 'Inter' (grotesque-style sans-serif) for a modern, objective, and highly readable look suitable for all text.
- Use clean, minimalist line-art icons that subtly convey actions like saving, sharing, or settings without distracting from the text.
- Implement a spacious and uncluttered layout, focusing on presenting one affirmation at a time. Generous whitespace should enhance focus and a sense of calm.
- Incorporate subtle and calming transitions for content loading and state changes, ensuring a smooth and serene user experience.
